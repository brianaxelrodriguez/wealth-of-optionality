# Source-material audit

The source package was inventoried before reconstructing the manuscript and repository. The audit covered 320 archive entries, 201 text/tabular/code files, and 13 notebooks. These counts describe the inventory procedure; they do not imply that every item provides valid empirical evidence.

The current repository preserves the source data needed for the reported descriptive exercises, the transformation scripts, and the derived tables. Candidate data extracted from portals remain blocked for regression use until units, definitions, frequency, coverage, identifiers, and provenance have been checked. A successful HTTP response or nonempty file is not evidence that the semantic content is correct.

## Material findings

- The two files labelled as international and Argentina corporate-liquidity extracts are byte-identical. The former therefore does not establish cross-country coverage.
- The merged WDI–PWT panel is an intersection of available country-year observations, not a universal panel.
- The listed-company accounting sample is selected and lacks invoice-level dates, counterparties, government-contract exposure, and verified exits.
- The public WBES catalogue/frequency tables are not a substitute for weighted establishment microdata with the survey design applied.
- The original model notebooks and scripts were treated as hypotheses to audit, not as authority to preserve every formula or simulated result.

## Reproducibility policy

Raw files are retained for provenance. Processed data are regenerated by scripts wherever possible. The SHA-256 manifest records the packaged files, while tests cover analytical functions and selected implementation invariants. Neither file hashes nor passing unit tests validate an economic interpretation or identify causal parameters.

Original raw-source filenames are intentionally preserved where changing them would weaken provenance or obscure the identity of the source extract. Generated code modules, processed outputs, figure filenames, documentation, and the public-facing repository interface use English names.
